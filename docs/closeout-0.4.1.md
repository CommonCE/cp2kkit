# 0.4.1 closeout and acceptance boundaries

Software remains **0.4.1** and data schema **0.1.0**. This is a software development
closeout, not scientific convergence or general installed-build certification.

## Included scope

- Retained density/surface work: native-grid plane averages, full-slab/cumulative
  electron integrals, skew-cell geometry, fixed-width CP2K scalar support and
  preparation-only surface examples.
- CUBE requests: opt-in potential/frontier-orbital output for target 2026.2 GPW
  Gamma, shared CLI/config/menu/CDD validation and unchanged hybrid restrictions.
- Native-format compatibility: exact producer-gated UKS total-density title;
  no new scalar type, automatic sign conversion or physical-default changes.
- Offline example: explicit plans, shared output/CUBE parsing, independent
  identity/convergence/exit checks and exclusive report publication.
- Regression evidence: small privacy-filtered native excerpts plus complete tiny
  synthetic fields, missing/failure evidence, status conflicts and collision tests.

See the [offline contract](../examples/cube-validation/README.md) and
[native-format provenance](../tests/fixtures/cube-native-041/README.md).
No new public audit CLI/API, scheduler client, quantum executor or dependency is
introduced. Unknown data remains null, not zero or success. Potential/orbital
scalar interpretation and scientific accuracy are not inferred from file integrity.

## Public distribution boundary

Public files exclude accounts, private absolute paths, job identities, execution
timestamps, cluster configuration and installation-specific failure reports.
Full original scientific evidence and pre-publication reports remain local,
outside Git; no raw calculation result is overwritten for publication cleanup.
Version-specific build/compiler defect claims are not established by these tests.

Native excerpts retain original full-source hashes/sizes and selected line numbers.
Their source paths are non-filesystem aliases, not fabricated public locators.
Private stderr/accounting captures are not published. Independent synthetic tests
retain failed-versus-successful exit handling without attaching it to a private
environment or a particular CP2K installation.

## Checks and remaining gates

The development baseline passed 83 focused and 633 full regression tests, with no
skips, plus compileall, version and whitespace checks. Publication cleanup requires
fresh tests and a staged-tree privacy review; the final delivery reports those
checks separately rather than treating historical counts as new results.

Before claiming package-release readiness, also check the distribution contents
and isolated installation. Before quantitative physical comparisons, converge the
state, basis/grid/cell and potential reference conventions. A public audit API or
broader method/version scope requires separate agreement. No tests or publication
step authorize quantum calculations or scheduler submissions.
